# Dating One

แอปหาเพื่อน/หาคู่ พัฒนาด้วย Flutter — เวอร์ชันนี้เป็น **หน้าบ้าน (Frontend)** พร้อมข้อมูลตัวอย่าง (Mock) ใช้งานได้จริงบนเครื่อง

## ฟีเจอร์

| แท็บ | รายละเอียด |
|------|------------|
| **หาเพื่อนใหม่** | แสดงสมาชิกเรียงจากใกล้ที่สุด สีพื้นหลังตามเพศ (ชมพู/ฟ้า/ม่วง พาสเทล) |
| **ฟีด** | โพสต์ล่าสุด กดใจ / ไม่ชอบ / คอมเมนต์ |
| **แชท** | รายการแชท + ส่งข้อความ (จำในเซสชัน) |
| **โปรไฟล์** | ข้อมูลผู้ใช้ สถิติเข้าชม/กดใจ + ตั้งค่าแก้ไขโปรไฟล์และรูป |

## รันบน Windows

```bash
cd D:\Weerawat\project-dating-one
flutter pub get
flutter run -d windows
```

## รันบน Android / iOS

```bash
flutter run
```

> รูปโปรไฟล์และโพสต์โหลดจากอินเทอร์เน็ต (pravatar.cc, picsum.photos) ต้องมีการเชื่อมต่อเครือข่าย
